# casa0014-vespera-controller

## What is Vespera?

Vespera is a WiFi-enabled interactive light installation developed for CASA0014 - Prototyping the Internet of Things.

The name “Vespera” comes from the Latin word *vesper*, meaning “evening”. It is also associated with the evening star, Venus, which becomes visible during the transition from daylight to night. The light installation represents the passage of time and the gradual appearance of a point of light as the sky becomes darker.

Vespera uses an Arduino MKR1010 and NeoPixel LEDs to display colours received through MQTT messages. Different devices can send messages to the system over WiFi, allowing users to interact with and control the light installation remotely.

## About This Project

This project is an Arduino-based physical controller (Arduino MKR WiFi 1010) for the Vespera light installation. It sends colour data to Vespera through MQTT, providing a tangible interface for interacting with the lights.

More information about the original Vespera project can be found in the [CASA0014 Vespera documentation](https://github.com/ucl-casa-ce/casa0014/blob/main/vespera/readme.md).
